# Glossary

The vocabulary of paperly. Terms here are the canonical ones: if code, copy or a
drawing disagrees with this file, one of the two is wrong and we fix the code
or this file deliberately.

## Brand

**paperly** — the product. Always lowercase, never capitalised mid-sentence.

**paperly.** — the brand wordmark, *including* the trailing period. The period
is part of the mark and is rendered in the accent colour, not in ink. It is a
deliberate echo of the voice ("a little less paperwork") and not a sentence
punctuation mark, so it is never doubled, dropped or replaced by another glyph.
Wherever the wordmark appears — app header, footer, thumbnail, favicon lockup —
the dot is present.

**the dot** — the accent-coloured period that ends the wordmark. One term, so it
is not also called "the full stop", "the punctuation" or "the accent mark".

**brand mark** — the coral rounded square containing the folded-corner document
glyph. The mark and the wordmark together form the **lockup**.

**lockup** — the fixed arrangement of brand mark and wordmark used on a product
tile. The lockup has a defined size ladder and must stay legible down to 48px.

## Product

**tool** — one of the 20 PDF operations a person can run (Merge PDF, Split PDF,
and so on). A tool is not a *category* and not a *job*.

**category** — one of the four groupings: Organize, Convert, Edit & optimize,
Security. Every tool belongs to exactly one category. A category owns a colour
(coral, blue, purple, green) that its tools and its nav icon share.

**job** — one completed run of a tool over some files. A job is metadata only
(tool, file name, sizes, page count) and never the file contents.

**workspace** — a private per-visitor collection of favorites, a name, and job
history. A workspace is identified by a cookie, not by an account, because
paperly has no sign-up.

**history** — the list of a workspace's jobs. History rows that reached the
database are **saved**; rows still only on the device are **pending**. History
never stores document contents.

## Delivery

**on-device** — processing that happens in the browser. Every tool is
on-device. This is the product's central claim and the word used for it, not
"client-side", "local" or "offline" (offline is a separate property).

**thumbnail** — the square brand tile. **social preview / OG image** — the wide
crop shown when a link is shared. These are two exports of one lockup, not two
designs.
